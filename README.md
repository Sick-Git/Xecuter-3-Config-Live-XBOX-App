Config Live 4026 App for Original Xbox.

Use on your HDD. Just add the XBE and launch it. No need to hold the white button. All persistence settings load to file.

This App was a huge amount of work. The original X3 Config Live was extracted and then reverse engineered, heavily modified, bugs fixed and updated to version 4026 and made into an App.

Flash chip ID Patches for AMD/Fujitsu with 01 & 04 main flash ID and also 256K Backup flash cleared ID checking for use with any suitable structured backup chip. (The original EON X3 backup chip long exhausted)

CPLD Xecuter 3 chip detection removed - allows booting via any bios.

Config read/write dispatch (D3D cave) constructed.

HDD Access fix.

Config persistence - save/load to file.

Trampoline (write wrapper + auto-load)

Clock year of 2020 bug NOP'd. (v3294 Xecuter 3 bug)

Default year now sets 2026 -> (your settings remain afterwards)

Default month now sets January -> (your settings remain afterwards)
